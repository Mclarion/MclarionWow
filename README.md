The first two owners' numeric captures predate this release; the metadata row is **new in installed 0.12.6 and live-test pending**. Automatic preferences default off on a new profile (existing choices can differ). Scans require world entry, out-of-combat and validated non-secret API data. Legacy manual Scan requires its preference; the six progression Scan actions do not require their corresponding auto preference. Opening or navigating the dashboard never scans or changes consent.

Money/currency/rank bursts debounce from the first notification (0.35 seconds); same-second/unavailable work retains bounded retries up to 300 seconds. Event payloads are ignored and world/post-combat/timer fallbacks survive optional event-registration failure. UI attempts and changed-capture timestamps are **session-memory evidence**, not disk timestamps. WoW flushes SavedVariables on `/reload`, logout or normal exit; `Unchanged` need not mean a failed scan.

## Save ownership and import boundary

Original addon: **only** `MclarionWowData` (schema 1/2) in account `SavedVariables/MclarionWow.lua`. Dependent Progression: four independent schema-1 globals (`MclarionWowQuestData`, `MclarionWowReputationData`, `MclarionWowWealthData`, `MclarionWowHonorTitleData`) in separate `MclarionWowProgression.lua`. Optional Metadata depends on Progression and owns **only** `VaultkeeperMetadataData` in separate `VaultkeeperMetadata.lua`. These game-written files are not same-named source files under `Interface/AddOns`. Do **not** select companion or metadata files for the existing legacy website/client importer. Legacy import requires deliberate selection of a WoW-written file, not automatic transfer; companion/metadata consumer support is unsupported/unverified. Never inspect player saves while WoW runs or publish identifiers.

`METADATA_CONTRACT.md` defines keys, provenance, optional fields, budgets and source evidence. Reputation/currency keys use type/ID/build/locale; **spell keys additionally include the observer GUID**. Spell descriptions are contextual `C_Spell.GetSpellDescription` text, not immutable damage/effect facts. Labels display only for matching observer/build/locale. New-owner enrichment is implemented for faction/reputation, currencies and consented cast-observed spells **only**. Existing item `MHWOWI1` metadata stays in the legacy pipeline. Maps, titles, talents, professions and recipes are pending metadata work; **quests are excluded** from the shared metadata catalog (numeric active quest observations remain). See `DATA_STORAGE.md` for full field/display limits and `PROGRESSION_CONTRACT.md` for progression scope.
